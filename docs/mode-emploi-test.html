WoocLight

Mode d'emploi pour tester l'application — version du 14/10/2026

Adresses

  • Espace animateur : https://wooclight.alwaysdata.net/admin.php
  • Participants : https://wooclight.alwaysdata.net (ou le QR code)
  • Projection : bouton Ouvrir la projection dans l'espace animateur

Pour un test complet : un ordinateur (animateur + projection dans deux onglets ou deux écrans) et deux téléphones (vous et un collègue), pour voir plusieurs réponses.

1. Préparer une session

  1. Connectez-vous à l'espace animateur avec votre mot de passe.
  2. Tapez un titre dans « Titre de la nouvelle session », puis Créer. Un code de 5 caractères et un QR code sont générés.
  3. + Ajouter une question : choisissez le type, écrivez l'intitulé, complétez les champs proposés, puis Enregistrer.
  4. Réordonnez avec ↑ ↓, corrigez avec Modifier.

Réglage « Correction et résultats »Effet
Quand je clique sur « Afficher les résultats » (par défaut)Vous choisissez le moment : la correction et les barres apparaissent ensemble, sur la projection et les téléphones.
Automatiquement à la fin du tempsDifféré : dès que le compte à rebours atteint zéro, tout s'affiche sans clic. Une durée est obligatoire.
ImmédiateChaque participant voit « Bonne réponse ! » ou la correction dès qu'il a répondu ; sa réponse est alors figée. La projection, elle, attend votre clic.

« Durée » : 0 = pas de compte à rebours. « Modifier sa réponse » : autorisé par défaut tant que le vote est ouvert (sauf correction immédiate).

2. Animer en direct

  1. Ouvrir la projection puis Plein écran. L'écran d'accueil affiche l'adresse, le code en grand et le QR code. Thème clair si la salle est lumineuse.
  2. Les participants scannent le QR code (appareil photo du téléphone) ou tapent l'adresse puis le code. Le nombre de participants s'affiche en haut de la projection.
  3. Quand tout le monde est là : Fermer les inscriptions (personne d'autre ne peut rejoindre).
  4. Suivante → projette la question et ouvre le vote. Le nombre de réponses s'affiche en direct.
  5. Fermer le vote, puis Afficher les résultats.
  6. Suivante → pour enchaîner. ← Précédente revient en arrière (une question déjà jouée n'est pas rouverte). Réinitialiser efface les réponses de la question projetée.
Réponses écrites (réponse libre, mur, post-it) : relisez avant d'afficher. Masquer retire une réponse qui contient un nom ou une information personnelle. Pour le mur et le post-it, les participants ne voient les contributions des autres qu'après Publier.

Enchaînement « bilan » en 15 minutes

  1. Post-it collectif « Bilan » avec 3 colonnes : Points forts / Difficultés / Envies.
  2. Pendant que les post-its arrivent, regroupez les doublons : sous un post-it, liste Regrouper sous… ; changez de colonne avec Déplacer….
  3. Publier : tout le monde voit le tableau.
  4. Question suivante « Vote par gommettes » dont la source est ce post-it : chacun place 3 gommettes, le classement s'affiche.

3. Après l'atelier

  • Exporter en CSV (tout) pour votre bilan (s'ouvre dans Excel) ; CSV à diffuser exclut les réponses masquées ; Version imprimable pour un PDF.
  • Terminer la session : les téléphones affichent « Session terminée ».
  • Les sessions sont supprimées automatiquement 30 jours après votre dernière action, ou tout de suite avec Supprimer dans « Mes sessions ». Dupliquer réutilise les questions sans les réponses.

5. En cas de problème

Message ou symptômeQue faire
« Code inconnu ou session expirée »Vérifier les 5 caractères ; la session a peut-être été supprimée.
« Le vote n'est pas encore ouvert » / « fermé »Côté animateur : Ouvrir le vote.
« Connexion perdue »Attendre : reconnexion automatique, la réponse en attente repart seule.
« Trop de tentatives » à la connexionAttendre 15 minutes (ou se connecter depuis un appareil déjà utilisé).
Reconnexion demandée en pleine séanceSécurité : 2 h sans action ou 12 h après la connexion. Se reconnecter.
La projection ne bouge plusRecharger la page (F5) : rien n'est perdu.

Notez ce qui ne va pas (étape, téléphone utilisé, message exact) ; une capture d'écran recadrée, sans nom de participant, aide beaucoup.
